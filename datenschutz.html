Welche Daten greift das Programm ab?

Nach deiner ausdrücklichen Zustimmung greift das Programm über die Gmail-API (Berechtigung gmail.modify) auf dein Gmail-Konto zu. Es liest Absender, Betreff, Größe, Labels und Status von Nachrichten, verschiebt Nachrichten in den Papierkorb, archiviert sie und legt Labels an oder vergibt sie. Nachrichten werden nicht endgültig gelöscht und keine Mails gesendet.

Wo werden Daten verarbeitet?

Ausschließlich lokal auf deinem Computer. Der Entwickler betreibt keinen Server und erhält keine Mails, Absenderlisten, Zugangsdaten oder Nutzungsdaten. Es gibt keine Weitergabe an Dritte, keine Werbung, kein Tracking und keine Analyse.

Was wird gespeichert?

Auf deinem Computer (Ordner %LOCALAPPDATA%\PostAufraeumen) werden deine Einstellungen, ein Protokoll und das Google-Anmeldetoken gespeichert. Das Token ermöglicht, dass du dich nicht jedes Mal neu anmelden musst.

Widerruf und Löschung

Du kannst den Zugriff jederzeit unter myaccount.google.com/permissions entziehen. Lösche den Ordner %LOCALAPPDATA%\PostAufraeumen, um alle lokalen Daten zu entfernen.

Google-API-Nutzerdaten

Die Nutzung und Übertragung von Informationen, die von Google-APIs erhalten werden, durch Post aufräumen entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).
